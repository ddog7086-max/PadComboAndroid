# v1.3 斜線除錯指引與下輪迭代規格

> 對象：`overlay/RouteBoardView.kt`（v1.2 / v1.3 已落地：同向合併、重訪車道、固定法向、分軸累積、圓角、邊界夾取、箭頭回保）。
> 標記：【已確認】現行程式可對應；【推估】依程式脈絡判斷，需截圖定位；【待驗證】需實機開關對照才能定案。
> 鐵律：本輪只調渲染幾何，**不更動** `BeamSearchSolver` 搜尋語意、path 步數、起終點與交換順序。

---

## 1. 轉彎與終點前斜線：成因分析

### 1.1 分軸偏移混用 / 車道切換點被壓縮
【已確認】頂點偏移採分軸累積：X 只取垂直鄰邊、Y 只取水平鄰邊。角點同時帶 X（來自垂直邊）與 Y（來自水平邊）是正常的「兩條錯開線的交會角」，不應視為斜線。

【推估】易出斜線的情形：
- 某個車道切換點（重訪邊交界、Pass 次序變換點）在同向合併時被刪除，兩個保留點之間跨越了不同車道槽位，連線直接把偏移差「斜著拉過去」。
- 水平段與垂直段在角點的槽位不對稱：一側在 ±槽、另一側在中線，角點被同時往兩軸拉，圓角又沒兜住，看起來像斜切。

定位：印出壓縮前後的 `pts`（格座標 + 像素 + ox/oy），檢查被刪除的點是否正好落在重訪邊或 Pass 邊界上；若刪除點兩側槽位不同，該點必須保留。

### 1.2 圓角半徑與邊界夾取拉歪端點 / 控制點
【已確認】`buildRoundedPath`：圓角控制點＝角點本身，`pA/pB` 沿兩腳退 `r`；半徑 `r = min(radius, l1/2, l2/2)`；所有點過 `clampPointToBoard`。

【推估】夾取造成斜線的機制：
- `clampPointToBoard` 對 X、Y 獨立夾取。靠近頂部 / 左右邊界時，偏移點可能只有一個軸被夾回內框，另一軸仍保留偏移，於是內部自由點與邊界夾回點之間形成斜線。
- 頂部折返處垂直槽位的 Y 偏移被 `insetTop` 截住，角點 Y 被壓低、水平段 Y 還在原位，兩點連線傾斜。
- 圓角控制點先夾取、`pA/pB` 後算，若兩腳長度差很多，`r` 被短腳壓小，圓角兜不住兩側槽位差，露出尖角斜切。

定位：把偏移關掉再看是否仍斜；若關偏移就正，問題在夾取 / 槽位；若仍斜，問題在圓角或壓縮。

### 1.3 終點箭嘴錨點與前段不同軸
【推估 · 高機率】現行 v1.3：最後一點的 Y 偏移回壓到 35%（`oy *= 0.35f`），但倒數第二點仍保留完整水平車道偏移。最後一段於是由「完整槽位 Y」斜著收斂回「接近珠心的終點」，這正是「箭嘴前段偏斜」的常見成因。

【已確認】箭頭朝向用 `end − prev` 方向；若 `prev` 被車道偏移拉離、`end` 被回保珠心，箭頭基線也會跟著偏。

修復方向（二選一，先實測）：
- **方案 A（推薦）**：最後一條邊整段回到中心線，不在終點段做水平車道；偏移在倒數第二個角點之前結束，末段筆直貼珠心。
- **方案 B**：末段兩端偏移同比例漸減（`prev` 與 `end` 一起往中線收），不要只壓終點。

### 1.4 同向合併條件過寬
【已確認】保留條件：起終點、方向改變、即時掉頭、重訪邊、重訪格。
【推估】可能不足的保留項：Pass 次序變換點、槽位切換點。目前這些若被判定成「同向」而刪除，會在兩槽位間產生斜拉直線。
【待驗證】實機開 / 關合併對照：關掉合併後斜線消失，代表保留條件要補槽位邊界點；合併開關本身不影響搜尋路徑。

### 1.5 快取 / 重用幾何狀態殘留
【已確認】`route` 為欄位；現行程式在 `onDraw` 內呼叫 `buildOffsetPoints`（每次繪圖重算幾何），Paint / Path 為局部或復用物件。
【推估】殘留風險不高，但需檢查：`boardRect` 更新後舊 route 是否仍用舊矩形算點；`segOffset` / `edgeRank` 陣列每次重建，未跨 route 殘留。
【待驗證】切換盤面後若線條還停在上一盤位置，才是狀態殘留；先確認是否為辨識 ROI / `boardRect` 飄移，而非 Path 快取。

## 2. 分步排查與修復策略（由簡入繁）

> 每一步只開 / 關一個開關，截圖對照，定位到單一變因；全部開關只影響繪圖。

### 2.1 基線：格軸對齊確認
1. 關閉所有車道偏移（水平 / 垂直槽位全 0）、關圓角（半徑 0）、關箭頭、暫停合併。
2. 此時線條應嚴格沿珠心橫平豎直。若仍斜：問題在 `boardRect` 對位、格心座標或原始序列，回查 `BoardRectHelper` 與辨識 ROI，不要先改畫圖。

### 2.2 開回同向合併
3. 開合併、其餘仍關。看直線段是否乾淨；若出現斜拉，補保留條件：槽位變換點、Pass 邊界點一併 `keep`。

### 2.3 開回偏移（先水平、再垂直）
4. 只開水平帶偏移：檢查同 row 多條折返的上下錯開；角點 Y 是否被拉斜。
5. 只開垂直重訪車道：檢查左右錯開；交叉點是否黏連。
6. 兩者都開，確認分軸累積沒有把 X/Y 混到同一邊。

### 2.4 開回圓角
7. 半徑從 0 逐步調回 0.16·cell；短段自動取 `min(l1/2, l2/2)`。
8. 若角點斜切來自夾取：先把邊界附近的偏移點在夾取前記錄原始 / 夾回座標，確認是哪一軸被截；必要時邊界段不套用車道偏移，而不是放寬 clamp。

### 2.5 開回終點箭嘴
9. 先套方案 A：末段整段中線；看箭嘴前段是否還斜。
10. 若要保留末段車道，再套方案 B 兩端同漸減。箭頭頂點 / 左右翼維持 `clampPointToBoard`。

### 2.6 幾何狀態核查
11. 確認 `show()` 傳入的 `path` 與 `boardRect` 同盤一致；切盤後 `clearRoute()` 舊線清空。
12. 效能核查：幾何若要移到 `show()` 算一次快取，需在 `boardRect` 或 path 變更時失效重算；避免快取舊槽位。

### 2.7 不可更動項
- `BeamSearchSolver.beamSearch` / `evaluatePath` / `applyDragPath` 的序列與步數不動。
- 重訪統計、Pass 分組永遠在原始邊序列上算；合併只產生畫圖副本。

## 3. v1.3 增量銜接與驗收清單

### 3.1 王字水平帶分層（渲染層，已進 v1.3，實機確認）
- 連續同 row 水平邊 → 一條 Pass；帶內 `visitRank`。
- 槽距 `0.10–0.12 cell`（現行 0.11）；單帶上限 3 條；總偏移 ≤ `0.28 cell`。
- 水平沿 Y 開槽、垂直沿 X 開槽；超額複用外槽、後畫壓上；不加步號 / 複線。
- 銜接斜線修正時，補上「Pass 邊界 / 槽位切換點保留」，避免分層線被合併斜拉。

### 3.2 Combo 結算核對（語意層，與渲染分開）
【已確認】現行 `resolveChain` 頂部以隨機 RNG 補珠；`evaluatePath` 把所有波次 combo 同權重計分。
【推估】偏高主因：補珠隨機樣本放大後續波次、第一波與投機波次信心混算、重力模型差異、未建模珠種。
【待驗證】
- 固定盤面同一 path 重跑 20 次，記錄 combo 方差；方差 >0 即先處理補珠確定性。
- 分開輸出 wave1（高信心）與 wave2+（預測）；對照真機實際成立波次。
- 逐格比對 `beforeBoard → nextBoard` 下落結果；排查 clearedCells 是否跨波次重複。

### 3.3 前後截圖驗收
| 區域 | v1.2 / 現況 | v1.3 驗收標準 |
|---|---|---|
| 直線段 | 同向連段有小斜折 | 中間無斜折，首尾格不變 |
| 頂部折返 | 角點被夾取 / 槽位拉斜 | 橫平豎直，角點圓角自然，不貼邊外傾 |
| 井字交叉 | 橫豎重疊黏連 | 橫 Y 錯位、豎 X 錯位，交叉可分辨 |
| 王字水平帶 | 多條折返擠中線 | 上下層次清楚，單帶 ≤3 槽，不外推 |
| 終點箭嘴 | 前段斜收、箭頭偏 | 末段貼珠心，箭頭沿最後一段方向 |
| 底行 / 邊界 | 線條進深啡邊界 | 全部在盤內框，clipRect 兜底生效 |
| 長盤效能 | 15–20 步掉幀 | `onDraw` 無可見掉幀，幾何不每幀重算 |

### 3.4 驗收動作
1. 固定 5–8 張盤（短 / 中 / 長盤各覆蓋），同一路徑前後版本截圖並排。
2. 逐區域對照上表；回報時標註 row/col 與是「頂部折返 / 交叉 / 末段 / 底行」哪一類。
3. Combo 對照另記：app 顯示 combo、色數、真機 combo、成立波次；不在渲染截圖裡混評。
